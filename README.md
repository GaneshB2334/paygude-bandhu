# Paygude Bandhu — Pune's Favourite Chaha & Snacks

> **खाऊ पिऊ पायगुडे बंधू** | **आपलं पुणे आपला चहा...**

Official web application for **Paygude Bandhu (पायगुडे बंधू — सुप्रसिध्द चहा • स्नॅक्स)**, Pune's beloved Maharashtrian Chaha & Snacks brand serving across **10 outlets in Pune**.

## Features & Pages

- **Home (`/`)**: Hero with Shaniwar Wada illustration & signature Cutting Chaha + Vada Pav, Dubai Lucky Draw promo banner, Our Bestsellers showcase (Pohe, Vada Pav, Ghee Idli, Chaha), Why People Love Us, 10 Pune Branches quick-picker, and Franchise CTA.
- **About Us (`/about`)**: Brand story, Paygude Bandhu storefront showcase, 3-step Pune Journey, Core Values, Why Pune Loves Us, and interactive Customer Testimonials carousel.
- **Full Menu (`/menu`)**: 100% Pure Vegetarian menu with live search, category filter tabs (`Chaha & Beverages`, `Morning Breakfast`, `Maharashtrian Snacks`, `South Indian`, `Special Combos`), and Bestsellers toggle.
- **Branches (`/branches`)**: Interactive branch locator with live search across all 10 Pune outlets (Abhiruchi Mall Samor, Karvenagar, Dhayari, Deccan, Shastri Road, Ambegaon Pathar, Bharati Vidyapeeth, Bibwewadi, Warje, Lohgaon – Dhanori Road), instant call & Google Maps directions buttons, and an interactive illustrated Pune map.
- **Franchise (`/franchise`)**: Brand stats, partnership benefits, Express Kiosk & Signature Café models, 4-step onboarding roadmap, and interactive Franchise Application form.
- **Dubai Lucky Draw (`/offers`)**: Campaign landing page for the 20 Lucky Winners Dubai trip promotion.
- **Contact (`/contact`)**: Direct contact cards, bulk catering & general enquiry form, and interactive FAQ accordion.

## Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Fonts**: Plus Jakarta Sans, Noto Sans Devanagari, Kalam (`next/font/google`)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
